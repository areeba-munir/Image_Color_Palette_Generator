# 🎨 Image Color Palette Generator

A professional web application that extracts dominant color palettes from images using **Machine Learning (K-Means Clustering)**.

## 🚀 Features
* **K-Means Clustering:** Uses Scikit-Learn to group similar pixels for a diverse palette.
* **Pro Mode:** Includes a High-Res toggle to catch tiny color details.
* **Click-to-Copy:** Interactive HEX code boxes with clipboard functionality.
* **Customizable:** Users can choose between 5, 10, or 15 colors.

## 🛠️ Built With
* **Python** (NumPy, Pillow, Scikit-Learn)
* **Flask** (Backend Framework)
* **HTML/CSS/JS** (Frontend)
